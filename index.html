怎么参与

  • 先在币安 App 领 Agent ID（钱包 → 首页 banner → Agent ID），是 name.ai 形式的链上身份，每人一个、不可转让。
  • 用同一个地址连接本页 → 点「今日打卡」，在钱包里确认那一笔（只花 gas，没有金额）。
  • 没有 Agent ID 的地址会被合约直接拒绝（NOT_AGENT_ID）。
